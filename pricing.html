FAQ

Frequently Asked Questions

How does Liquid Glass perform on mobile?

Our shaders are built on native hardware-accelerated CSS backdrop-filter and CSS transform layers. On iOS and Android devices, it delivers silky smooth 60 FPS scrolling with minimal battery draw.

Is there a fallback for older browsers?

Yes. If a client browser does not support optical backdrop filters, our CSS automatically gracefully degrades to clean semi-translucent dark panels with full text contrast.

Can I customize the iridescent color palettes?

Absolutely. All gradient mesh blobs, border highlights, and specular reflections are bound to standard CSS Custom Properties that can be altered in real time.

Can I switch between monthly and annual plans?

Yes, you can upgrade, downgrade, or switch billing intervals at any point directly from the live dashboard console without any service disruption.
